## Authoritative capabilities

- [Git worktree manual](https://git-scm.com/docs/git-worktree): porcelain/NUL registered paths; locked/prunable state; clean removal, force and prune boundaries.
- [Git status manual](https://git-scm.com/docs/git-status): porcelain v1 NUL records, rename framing, untracked/ignored distinctions. Auditor sets `GIT_OPTIONAL_LOCKS=0` for status refresh avoidance.
- [Git merge-base manual](https://git-scm.com/docs/git-merge-base): ancestry success versus failure/error distinction.
- [Codex worktrees](https://learn.chatgpt.com/docs/environments/git-worktrees): app-managed lifecycle differs from ordinary linked checkouts. The research host's exposed artifact/archive tool contracts describe recoverable snapshots and restrictions for primary, pinned, shared, embedded-repository and initialized-submodule checkouts; plugin installation does not grant those tools. The playbook requires binding recipient tools and exact returned identities, otherwise holds potentially managed checkouts.
- [Shared history](../references/history.md) and [delegation](../references/delegation.md) supply scoped-reader and bounded-worker prerequisites. Missing reader/liveness is a documented conditional capability, never a safe classification.

## Deterministic evidence and limits

Direct disposable-repository exercise established two NUL-delimited worktrees with space-containing paths, symlink-canonicalized identity, tracked WIP, untracked and ignored names, unchanged before/after Git status, rename source/destination framing, and missing/pinned/recent/stale activity branches. Initial fixture assertion used the platform's temporary symlink spelling rather than the auditor's canonical spelling; corrected the assertion and reran successfully. No user work was deleted. The fixture was created outside the package; no mandatory test suite is introduced.

Source control-flow inspection: subprocess calls are Git discovery/status/log/ref comparison/ancestry and optional `gh pr list`; there is no fetch/remove/prune/write command. JSON output is the only helper output write; credential-helper behavior and operating-system reads remain environmental premises. Python may create bytecode when imported by an external caller; normal direct execution does not import this local module. `os.walk` avoids following directory symlinks, propagates unreadable size as unknown, and does not mutate files. Every incomplete per-worktree audit becomes hold-review; no deletion logic exists. `candidate-needs-confirmation` requires no hold reason and still demands current human/host lifecycle confirmation. Activity coverage, PR pagination limit, concurrent Git changes and ref freshness are reported/rechecked in the playbook, not probabilistically proven by this audit.

Package provenance/reference validator passed with this slice. No live agent, recipient install, history reader, archive, PR query or simulator operation is claimed established. Remaining conditional prerequisites are ordinary declared runtime dependencies, not silently omitted cleanup requirements.
