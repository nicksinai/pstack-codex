- **K2 — local workers.** Official [Codex subagents](https://developers.openai.com/codex/subagents), retrieved October 12, 2026, documents desktop delegation directed by selected instructions, native model/effort choices and lifecycle operations. [Delegation](../references/delegation.md) and [models](../references/models.md) own schema detection, actual role resolution, isolated writing checkouts, bounded fan-out, live resource ownership, parent review and fresh/resume behavior. This slice explicitly requests its workers. Established instruction substitution; exposed recipient operations, model permissions, filesystem/shell access and actual execution remain conditional. Local GPT workers replace Cursor dispatch and Grok defaults; provider diversity is absent.
- **K3 — capture, probe, query and measurement.** Packaging supplies no profiler, parser, CDP connection or application permission (C6). [Performance setup](../references/performance.md) requires checking the actual available tools and binding the exact target, source, workload, command and artifacts. The implementation session has filesystem/shell tools, but that does not establish recipient profiling or live access. Established preflight/blocking guard; every actual capture, live probe, symbol resolution, SQLite transformation and measurement remains conditional on target-compatible tools, permissions and real evidence. Missing operations are reported at the exact gate, never labeled PASS. The control adapters are required package contracts at `references/control-ui.md` and `references/control-cli.md`; their implementation/whole-package closure belongs to issue #10/#15. No new runtime or entitlement is claimed here.
- **K4 — delivery, trail and continuation.** [PR delivery](../references/pr-delivery.md), [Opening a PR](../playbooks/opening-a-pr.md), [show-me-your-work](../skills/pstack-show-me-your-work/SKILL.md) and [continuation](../references/continuation.md) are the authoritative integrated contracts. Actual forge access, transcript access, independent trail review and requested scheduling remain conditional on their own capability checks. Installation and PR preparation grant no merge/deploy authority. Unattended work runs only while the local environment is available.

In the tables, **established** means the instruction/gate/reference is present and source-preserved under the listed substitutions. It never means a task was run successfully. **Conditional** identifies the required runtime premise. **Unresolved** would identify a requirement lacking an adapter or evidence argument; none of the six owned source artifacts is omitted. Cross-slice adapters must exist before their routes execute, and final package closure must account for them.
