## Capability premises

- [Codex skills](https://developers.openai.com/codex/skills) documents explicit invocation and `agents/openai.yaml` `allow_implicit_invocation:false`. It supplies no documented native Cursor mode/reminder equivalent. [Continuation](../references/continuation.md) therefore records explicit conversation/workspace-bound entry/exit in host task context and recipient-owned private checkpoints. Reload after compaction/restart remains conditional on accessible records and instruction compliance.
- [Subagents](https://developers.openai.com/codex/subagents) documents desktop delegation, controls and model/effort configuration; actual recipient schemas/capacity must be inspected. [Delegation](../references/delegation.md) and [models](../references/models.md) govern all workers. Local worktree workers share services/resources and replace cloud VMs. Native GPT-only reviewers do not supply provider diversity.
- [Scheduled tasks](https://learn.chatgpt.com/docs/automations) documents chat schedules and local execution while the app/computer/project are available. Available account scheduler operations and returned IDs are runtime premises. Active waits are not schedules; no persistent loop service is bundled. Scheduling requires a user request.
- [App Server](https://learn.chatgpt.com/docs/app-server) distinguishes full stored turns from summaries, but does not establish a recipient agent-callable reader. [History](../references/history.md) binds actual scoped readers/exports and [session pickup](../references/session-pickup.md) owns reconstruction. Full trail auditing is conditional on original execution records, not retrieval summaries.
- Bash with standard date/tr/dirname/mkdir utilities supports the preserved logging helper. Node.js with built-in fs/process supports the adapted plan checker, with no npm/Bun installation or network bootstrap. File writes, Git/forge, control-surface tools, checkpoints and requested schedules remain recipient environmental prerequisites. This ticket performs no installation or scheduling.
