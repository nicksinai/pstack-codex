## Reference closure and limits

All Markdown links introduced by this slice resolve to package-local existing files. Full-mode initialization names a staged path and explicitly blocks until its required mode source exists; no link pretends the missing file is present. The optional verification-skill offer names a later slice and reports absence instead of executing a phantom skill. How/swarm use their complete bundled specialized prompts and shared contracts, independently of full mode.

The package requires current host delegation, model/effort validation, result reception and write isolation capabilities. Each workflow preflights the relevant subset. Missing core operations produce an exact BLOCKED report and request a scope decision, never a single-agent simulation labeled equivalent. Official docs support the capabilities generally; a friend's specific installation, permissions, tool catalog and entitlement remain conditional. The unknown nesting limit is handled by discovered limits/host rejection and ancestor delegation, not a claimed fixed depth.

No new executable runtime, hard-coded model entitlement, global custom-agent installation, credential, personal path or account configuration is added. Mode defaults now inherit the parent until the recipient configures roles, explicitly losing default cross-provider specialization. GPT-only independence does not reproduce provider diversity. Local availability, costs, scheduling and service access differ from cloud execution. These are agreed substitutions.
