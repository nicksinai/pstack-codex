## Capability evidence and assumptions

The shared [capability evidence](capabilities.md) records official [plugin distribution](https://developers.openai.com/plugins/build/plugins), [skill invocation](https://developers.openai.com/codex/skills), [local subagents](https://developers.openai.com/codex/subagents) and [local automations](https://learn.chatgpt.com/docs/automations). These establish documented host contracts, not a promise that the recipient exposes the implementation chat's tool catalog. Explicit-only metadata is set on both new skill entries. The installed wrapper is plain bundled instruction material, not a falsely declared automatically installed custom agent.

GitHub watcher API behavior is inherited from the inspected pinned helper and conditional on authenticated gh and current GitHub responses. Origin is an optional preserved CLI path; no installed Origin or runtime success is claimed. Current forge status, required review rules, merge permissions and model availability require live preflight. Independent GPT reviewers do not supply upstream provider diversity. Active background waits are not durable scheduling. Host authority can forbid posting even when upstream expects it; retained local verdicts never masquerade as posted ones.
