## Approval, privacy and enforcement argument

Reviewers and synthesizer make no writes by instruction; this does not claim sandbox enforcement. Transcript and reviewer outputs remain untrusted evidence, with cited-context-only lookups. Synthesizer must read the target before accepting a body edit; missed-trigger description proposals respect intentionally explicit-only policy. An Accepted proposal cannot reach edit routing before full-output presentation and explicit subset approval. Mechanism candidates leave Accepted for Backlog. Existing tracker authority gates filing separately, so no user preference or plugin installation can fabricate account write access. Managed plugin/system changes use authorized source or recipient override with reviewable diff; personal transcripts and lessons do not enter the distributable. These are source-established instruction invariants, with agent compliance and recipient capability conditional.
