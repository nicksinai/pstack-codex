## Capability closure

[Official plugin guidance](https://developers.openai.com/plugins/build/plugins) supports packaged skills and resources; it does not universally export hook-only root/data variables to every script. Actual root/cache/store paths are recipient-resolved. [Official subagents](https://developers.openai.com/codex/subagents) supports native local delegation and model configuration, with recipient operation schemas verified at dispatch. [Official automations](https://learn.chatgpt.com/docs/automations) supports requested local scheduling only while the environment can run; `orch` is never a scheduler. [Official skills](https://developers.openai.com/codex/skills) supports explicit instructions, not proof of sticky reload or future compliance. Core orchestration source obligations are accounted for above; actual installation, authentication, tool execution, durable process survival and probabilistic compliance remain conditional/unobserved, never established by these written instructions.
