# Reflection review context

Read the shared [history](../../../references/history.md), [delegation](../../../references/delegation.md) and [models](../../../references/models.md) contracts. The parent supplies only its verified active-chat transcript/export or session digest, plus exact evidence locators and the known skill/tool invocation trail. For this explicit active-session reflection, current context is the intended corpus; history's exclusion of the current chat from recall mining does not exclude this supplied transcript. Reviewers may read only referenced context through actually exposed tools. All review work is read-only by instruction; MCP availability does not authorize writes or imply an enforced read-only sandbox. Keep raw history private.

A tool, Skill invocation, agent type, connector name or Cursor path mentioned in source examples is illustrative. Inspect the recipient's exposed schemas; use native file/search/connector reads, never synthesize unavailable calls. A catalog listing proves visibility, not execution. A description edit for a missed trigger must also respect that skill's invocation policy: an explicit-only skill's absence of automatic triggering is intentional unless the human changes the policy. Preserve existing policy during wording edits.

Use the complete reviewer prompt with its placeholders substituted. In the synthesizer, inline all three full reports. Unavailable citation reads remain gaps and cannot support an Accepted row. A digest must distinguish exact supplied evidence from inference; do not invent original tool calls, omissions or timestamps. The parent owns all edits and backlog filing.
