# Source access and tool binding

This adapter governs every why investigator and synthesizer, including recall's shared-record sweep. The sibling source playbooks preserve upstream query strategies and expected evidence. Their named APIs are examples. Bind each action to the actual exposed schema before use; do not call a guessed endpoint or treat a named MCP as authenticated access.

Use read operations only, within the user's target, organization/project, time range and source permissions. Broad-first searching means broader relevant keywords within that boundary, not unrelated personal spaces. Author searches remain within the authorized work context. Fetch full candidate records and paginate comments/threads/results as required. Record filters, queries, page coverage, inaccessible links, retention limits, and truncation. A search preview is a lead, not full evidence. If source terms limit quotation or export, preserve precise citations and compliant excerpts/paraphrases rather than bulk copying.

Build a coverage row for each of the seven categories: endpoint, supported read operations, auth/access status, relevant project scope, investigator, queries performed, result or gap, and skip reason. Unavailable, unauthenticated, permission denied, empty, provably irrelevant and partially searched are different results. Report auth failure; use the host's supported user authentication handoff if appropriate. Never fabricate a successful sweep or mutate a connector to make it readable. Local Git history can still be investigated when forge discussion is unavailable; record that reduced coverage.

Give investigators and synthesizer the same scope/authority limits alongside their original prompts. No posting messages, editing tickets, issuing warehouse writes, changing dashboards, triggering costly analysis services or resolving errors follows from a request to explain rationale. Prefer existing read-only queries; any extra action requiring authorization remains separate. Cross-source leads return to the owner, who routes them to the assigned investigator without widening scope silently.

Keep raw private source records in the scoped workers. The coordinator receives relevant findings, exact citations, conflicts and gaps. Sanitize private context before public output; a citation to an inaccessible private source is not permission to publish its contents. Public teaching or PR text must respect the intended audience.

The source-control playbook's `gh` examples require the correct authenticated repository. Inspect its remote and use explicit repo selection where ambiguity exists. Git commands are scoped to the active checkout and quote paths. Do not equate a merged PR with deployed behavior or a marked-resolved incident with a proven fix.
