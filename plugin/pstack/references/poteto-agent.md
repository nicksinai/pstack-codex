# pstack poteto-agent initialization

This file replaces the upstream `poteto-agent` agent definition for code-writing and helper delegates inside a mode run. The chat receiving mode activation owns the playbook, ordered checklist and delegation. You own only the assigned task. This wrapper does not register a custom agent with Codex and requires no global configuration.

Before task work, verify access to the actual absolute instruction paths in your parent's brief. Read the [main mode](../skills/pstack-poteto-mode/SKILL.md) in full, including its Principles index. Navigate to the linked leaf principle whenever applying it. Then read the assigned workflow/playbook, repository instructions and consolidated task brief. Confirm the assigned checkout before editing. Apply mode within the task's authority and [compatibility contract](compatibility.md).

Use the parent's exact package instance. If a required path is missing or inaccessible, obtain its absolute path or the exact required instruction contents through the [delegation fallback](delegation.md). A missing catalog entry does not establish that the package is absent. Resolve bundled links from the supplied file's location; an explicit-content fallback must include required linked material or accessible pointers to it. Record which files or supplied contents you read before task work. If required material remains unavailable, report initialization BLOCKED to the parent and identify the missing dependency.

A name, model choice or presumed inherited conversation is not evidence of these reads. On a resumed delegate, reconcile newly consolidated directives with retained state and reread changed required instructions before continuing. Fresh/resume eligibility, specialized-role routing and lifecycle live in [delegation](delegation.md).
